# acvi.net

**acvi** (Acoustic · Vibration) — 소리와 진동을 재고, 잰 것으로 답을 만드는 김태연의 작업실 사이트입니다.
공모전 하나를 회사의 프로젝트 실적처럼 한 페이지씩 기록합니다.

https://acvi.net

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 홈. 첫 화면 → 결과물 띠 → 하는 일 → 프로젝트 → 함께한 기관 → 일하는 방식 → 숫자 → 상장 → 소식 → 소개·연락 |
| `projects/<슬러그>.html` | 프로젝트 한 건 = 한 페이지. 현장과 문제 → 잰 것 → 만든 것 → 결과 → 증거 |
| `projects/_template.html` | 새 프로젝트 페이지를 만들 때 복사하는 틀 (사이트에는 노출되지 않음) |
| `assets/site.css` | 공용 스타일. 색·글꼴은 맨 위 `:root`에서 바꿉니다 |
| `assets/img/` | 이미지. 프로젝트별로 `img/<슬러그>/` 폴더를 둡니다 |
| `favicon.svg` | 브라우저 탭 아이콘 (감쇠 파형 로고) |
| `CNAME` | 사용자 지정 도메인 `acvi.net` 연결. **지우면 도메인 연결이 풀립니다.** |

자바스크립트는 쓰지 않습니다. 모든 페이지가 HTML과 CSS만으로 동작합니다.

## 프로젝트 추가하기

1. `projects/_template.html`을 `projects/<슬러그>.html`로 복사합니다. 슬러그는 영문 소문자(예: `aitkoo`, `go-no-go`).
2. `[대괄호]` 안을 채웁니다. 없는 항목은 그 줄을 지웁니다.
3. 이미지는 `assets/img/<슬러그>/`에 넣고, 자리표시 `<div class="ph">…</div>`를 `<img class="cover" src="../assets/img/<슬러그>/<파일>" alt="…">`로 바꿉니다.
4. `index.html`의 프로젝트 목록에서 그 항목의 `<div class="prow">`를 `<a class="prow" href="projects/<슬러그>.html">`로 바꾸고, `상세 준비 중` 꼬리표를 지웁니다.
5. 홈의 숫자(프로젝트 · 수상 · 대상 · 보도), 상장, 소식 칸도 맞춰 고칩니다.

## 문장 규칙

- 사이트에 보이는 문장은 **'~다' 평서체 또는 명사형**으로 끝낸다. `~입니다`, `~습니다`, `~해요`, `~주세요`는 쓰지 않는다.
- '하는 일'은 서비스 이름만 적는다. 설명·예시·꼬리표는 넣지 않는다.
- 프로젝트 제목은 한 줄, 본문은 현장과 문제 → 잰 것 → 만든 것 → 결과 → 증거 순서.

## 이미지 자리

아직 이미지가 없는 곳은 점선 상자(`.ph`)에 `[이미지] 무엇`으로 표시돼 있습니다. 실제 파일이 생기는 대로 하나씩 바꿉니다.

## 배포

`main` 브랜치에 병합되면 GitHub Pages가 자동으로 배포합니다. 보통 1~2분 안에 반영됩니다.

작업은 `feat/…`, `fix/…`, `docs/…` 브랜치에서 하고, Pull Request로 `main`에 병합합니다.
