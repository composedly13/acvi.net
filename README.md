# acvi.net

**acvi** (Acoustic · Vibration) — 소리와 진동을 재고, 잰 것으로 답을 만드는 1인 스튜디오의 웹사이트입니다.

https://acvi.net

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 사이트 전체. 화면·스타일·동작이 한 파일에 들어 있습니다. |
| `favicon.svg` | 브라우저 탭 아이콘 (감쇠 파형 로고) |
| `CNAME` | 사용자 지정 도메인 `acvi.net` 연결. **지우면 도메인 연결이 풀립니다.** |

## 화면 구조

- **메인 (한 화면):** 화면 전체가 하나의 진동하는 줄입니다. 마우스로 쓸거나 누르면 울렸다가 잦아듭니다.
- **패널:** 작업 · 하는 일 · 소개는 오른쪽에서 열리는 패널로 보여 줍니다. 주소 끝에 `#work`, `#services`, `#about`을 붙이면 해당 패널이 바로 열립니다.
- **소리:** 오른쪽 위 버튼으로 켜고 끕니다. 기본은 꺼져 있습니다.

## 기록 추가하기

`index.html` 아래쪽 스크립트의 `data` 배열에 한 줄을 추가합니다.

```js
{ date:'2026.11', rank:'대상', title:'대회 이름', sub:'주최 · 규모', lvl:5, m:'잰 것', s:'푼 방법' }
```

- `lvl` (1~5): 결과의 크기. 목록에 마우스를 올렸을 때 울리는 세기와 막대 표시에 쓰입니다.

## 배포

작업은 `feat/…`, `fix/…`, `docs/…` 브랜치에서 하고, Pull Request로 `main`에 병합합니다.
